About Me

hey, i'm adrian curammeng.

I'm a Software Development (BSD) student at Seneca Polytechnic, having previously graduated from the Computer Programming and Analysis (CPA) diploma program, also at Seneca Polytechnic.

I like to create things like websites, mobile applications, desktop applications, and even more! I learn by creating, by taking random ideas in my head and implementing those ideas into code.

Workflow

I work primarily in a terminal environment using a combination of WSL2, a tool that runs a Linux environment (Debian, in my case) on your Windows device, and Neovim, a terminal-based text editor that supports plugins using Lua scripts.

I actually have a repository that stores my entire Neovim configuration, which you can find here.
